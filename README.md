# Vorsorgemappe

Web-App für zwei Personen zum gemeinsamen Anlegen und Pflegen einer Bestattungsverfügung.
Speicher ist ein geteilter Dropbox-Ordner — kein Server, keine Konten, keine Datenbank.

Dieses Repository enthält **nur den Programmcode**. Alle Inhalte und Antworten liegen
ausschließlich in der Dropbox der Nutzer und sind hier nicht enthalten.
